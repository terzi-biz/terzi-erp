# Крок 2 — Прайси постачальників + Кошторис/КП

## Частина A. Імпорт прайсів постачальників (Excel + CSV)

### Нові файли
- `src/lib/price-import.ts` — парсер xlsx/csv, нормалізація колонок, fuzzy-match за назвою
- `src/components/PriceImportDialog.tsx` — модальне вікно: upload → preview таблиці → авто-матч → ручне підтвердження/корекція → "Застосувати"
- Збереження прайсів-постачальників у `useAppStore`: новий розділ `supplierPrices: SupplierPriceList[]`

### Логіка матчингу
- Авто за назвою (нормалізована Levenshtein/contains) проти `materialPrices` ключів + локалізованих назв i18n
- Для кожного рядка прайсу показуємо: запропонована позиція калькулятора + dropdown для зміни + чекбокс "застосувати"
- При застосуванні оновлюємо `buy` ціну позиції; історія в `supplierPrices` зберігається з датою і назвою постачальника

### UI
- Кнопка «Імпорт прайсу» у Settings → Матеріали/Роботи (для кожного модуля)
- Колонки прайсу: назва, одиниця, ціна, постачальник (опціонально SKU)

### Залежності
- `xlsx` (SheetJS) — для парсингу .xlsx; CSV парсимо вручну (split по , з підтримкою лапок)

## Частина B. Вкладка «Кошторис / КП»

### Архітектура
- У кожному з 4 файлів калькуляторів (`screed.tsx`, `roofing.tsx`, `insulation.tsx`, `demolition.tsx`) додаємо tab switcher вгорі: **Калькулятор | Кошторис / КП**
- Винесення спільної логіки в `src/components/EstimateView.tsx` — приймає `CalcResult` + `branding` + `client` + `module`

### Компонент EstimateView
- Підкладка з 2 субтабами: **Внутрішній** | **Клієнтський**
- Внутрішній: всі лінії (matetials/works/logistics) з колонками `Назва | К-сть | Од. | Закуп.ціна | Прод.ціна | Сума купівлі | Сума продажу | Маржа`, разом з підсумками `totalCost`, `totalClient`, `grossProfit`, `marginPercent`
- Клієнтський: групи з назвами, кількості, продажні ціни, сума; внизу `Разом`, термін дії, гарантія, умови оплати з `branding`
- Обидва: кнопки **Друк PDF** (`generateClientPdf` для клієнтського, новий `generateInternalPdf` для внутрішнього) + **Зображення** (PNG через існуючий `pngExport.ts`)

### Видимість
- Внутрішній субтаб видимий тільки `isInternal` (admin/director/finance); manager бачить лише клієнтський

## Технічні деталі
- Не змінюємо логіку калькуляторів — лише презентаційний шар
- Зберігаємо існуючу кнопку "Скачати PDF" у хедері (працює як швидкий експорт клієнтської версії)
- `pngExport.ts` вже існує — переюзаємо
- Новий `generateInternalPdf` у `src/lib/pdf.ts` — копія структури з додаванням колонок собівартості
