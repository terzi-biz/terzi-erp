# FINANCE.md — управлінський облік

## Обсяг

Рахунки (`invoices`, `invoice_lines`), платежі (`payments`), витрати (`expenses`),
каси/рахунки (`finance_accounts`), зарплати (`payroll_*`), борги, прибутковість
проєкту й компанії.

## Визначення

- **Платіж ≠ виручка.** Платіж — рух грошей; виручка визнається за затвердженим
  кошторисом/актом.
- **Кошторис ≠ фактична виручка.** Кошторис — план.
- **Собівартість** = матеріали + роботи + логістика + обладнання/амортизація + інше.
- Markup = (Price − Cost) / Cost × 100; Margin = (Price − Cost) / Price × 100.
- Борг = виставлено − оплачено (`invoices.total − invoices.paid`).

## Потоки

```text
Кошторис → Рахунок (invoice + lines) → Платіж (payments, direction=in)
   тригер sync_invoice_paid() → invoices.paid, status: issued/partial/paid
Списання зі складу (stock_documents out/writeoff) → expenses (source='stock')
Зарплата (payroll_entries) → expenses / P&L проєкту
```

## Податки

- ПДВ застосовується згідно налаштувань продавця (`src/lib/core/vat.ts`),
  за замовчуванням — на матеріали, коли увімкнено.
- Безготівка ФОП — коригування +6% (налаштовується).
- Ставка застосовується один раз до НЕТТО; подвійне нарахування виключене Core.

## Округлення

Розрахунки ведуться з повною точністю; округлення до 2 знаків — на фінальному
кроці формування рядка/підсумку.

## Доступ

Собівартість, закупівельні ціни, маржа, прибуток, ФОП і комісії — internal.
Менеджер продажів їх не бачить без окремого права. Клієнтські документи їх не містять.

## Звіти

Прибутковість проєкту, борги за клієнтами, cash-in/cash-out по періодах,
структура витрат, план/факт по замовленню. Джерело — `/finance`, `/reports`.
