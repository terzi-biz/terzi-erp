# ADR 0003 — канонічний реєстр модулів

Статус: прийнято

## Контекст

Підписи, маршрути й фільтри довідників для напрямків (стяжка, ПВХ, руберойд,
утеплення, демонтаж) дублювались у навігації, каталозі, історії й калькуляторах.
Невідомий модуль мовчки трактувався як «стяжка», що спотворювало кошториси.

## Рішення

`src/lib/modules.ts` — єдине джерело правди: `id`, `label`, `route`,
`catalogModule`, `estimateModule`, `hasCalculator`, `productionType`,
`permissions`, `active`. Навігація (`nav-model.ts`) і Calculation Core
(`core/module-registry.ts`) звіряються з реєстром у тестах.

Fallback «невідомий модуль → screed» видалено: `findModule()` повертає `null`,
викликач зобов'язаний обробити відсутність явно.

## Наслідки

- Новий напрямок додається в одному місці + маршрут + двигун + тест + e2e-рядок.
- Неактивні модулі не показуються в навігації, але лишаються валідними для історії.
- Помилковий `module` виявляється одразу, а не тихо рахується як стяжка.
