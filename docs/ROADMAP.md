# ROADMAP.md

## Q1 — стабільність і гігієна даних

1. Окреме dev-середовище БД; production ізольований від preview.
2. Reconciliation-міграції за `docs/SCHEMA_DRIFT.md`; чистий `db:reset` на нулі.
3. Soft delete (`deleted_at`) для `clients`, `orders`, `estimates`, `catalog_items`.
4. Backfill `estimates.client_id` / `order_id` через `/data-audit` з аудитом.
5. Storage-бакет для файлів замовлення + політики + UI завантаження.

## Q2 — фінанси й закупівлі

6. Повний цикл закупівель: потреба з кошторису → замовлення постачальнику → прихід.
7. Постачальники як окрема сутність із цінами й строками.
8. Розширений Project P&L: зарплати, амортизація, накладні за період.
9. Звіт cash-flow і платіжний календар.

## Q3 — виробництво й якість

10. Табель бригад і фактичні години в план/факт.
11. Акти виконаних робіт із контролем перевищення обсягів.
12. Чек-листи прийому й гарантійні звернення.
13. Оптимістичні блокування для карток замовлення й кошторису.

## Q4 — аналітика й інтеграції

14. Meta Ads і Google Ads у продуктиві (після стабілізації Binotel і keyCRM).
15. Зовнішній BI (read-only роль + дашборди керівництва).
16. Ретеншн і архівація `integration_events`, `audit_logs`.
17. Telegram-сповіщення за подіями замовлення й оплат.

Кожен пункт при старті отримує ADR, якщо змінює канонічну модель або межі шарів.
